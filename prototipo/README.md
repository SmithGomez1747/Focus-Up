# Prototipo de Focus Up

Esta carpeta contiene el prototipo de media fidelidad de Focus Up, desarrollado mediante HTML y CSS.

Su objetivo es representar visualmente las principales pantallas de la aplicación y mostrar las decisiones de diseño utilizadas.

## Archivos del prototipo

- `01_hoy.html`: pantalla principal con actividades y progreso.
- `02_nueva_actividad.html`: formulario para registrar actividades.
- `03_detalle_actividad.html`: información de la actividad registrada.
- `04_plan_por_pasos.html`: organización de actividades en pasos.
- `05_modo_enfoque.html`: pantalla de sesión de estudio.
- `06_progreso_confirmado.html`: confirmación del avance realizado.
- `estilos.css`: hoja de estilos compartida por las pantallas.

## Capturas

La carpeta `capturas/` contiene imágenes de las seis pantallas para facilitar su revisión.

## Cómo visualizar el prototipo

1. Descargar los archivos HTML y CSS.
2. Mantenerlos dentro de la misma carpeta.
3. Abrir `01_hoy.html` en un navegador.
4. Abrir los demás archivos HTML para visualizar las otras pantallas.

## Alcance

El prototipo permite observar la estructura, el diseño visual y los estados principales de Focus Up.

No constituye una aplicación completamente funcional. Las acciones, el almacenamiento de datos y los recordatorios reales no están implementados.
