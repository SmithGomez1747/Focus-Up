# Documentación de Focus Up

Esta carpeta contiene el informe académico definitivo del proyecto **Focus Up**, desarrollado para la asignatura Interacción Humano Computador de la Universidad Mayor.

El documento presenta el proceso de investigación propuesto, identificación de requisitos, diseño conceptual, arquitectura de información, decisiones visuales, prototipado y uso de GitHub para registrar los avances del proyecto.

## Archivos

- `Gómez-Smith_Núñez-Fernanda_EvaluaciónSumativa2_IHC 17.docx`: versión definitiva del informe en formato Word.
- `Gómez-Smith_Núñez-Fernanda_EvaluaciónSumativa2_IHC 17 .pdf`: versión definitiva del informe en formato PDF.

## Contenido

El informe incluye los nueve puntos desarrollados durante la evaluación sumativa, además de la introducción, las conclusiones, la bibliografía y las evidencias del trabajo realizado.

Se recomienda revisar la versión PDF para visualizar correctamente el formato, las tablas, los diagramas y las capturas incluidas en el documento.
