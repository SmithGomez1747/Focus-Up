# Diagramas de Focus Up

Esta carpeta contiene las representaciones visuales de la arquitectura de información y el flujo de usuario del proyecto Focus Up.

## Contenido

- **Mapa de contenidos:** muestra la organización de las secciones principales de la aplicación y sus relaciones.
- **Flujo de usuario:** representa el recorrido que realiza un estudiante para registrar una actividad, dividirla en pasos y visualizar su progreso.

Estos diagramas complementan el punto 6 del informe académico y permiten comprender cómo se organiza la navegación propuesta.
