Esta carpeta contiene las tablas y recursos visuales complementarios al informe académico del proyecto Focus Up, desarrollado para la asignatura Interacción Humano Computador de la Universidad Mayor.

Los anexos documentan las etapas del proceso de diseño, incluyendo la caracterización de usuarios, el mapa de empatía, los requisitos iniciales, la comparación de alternativas, el modelo conceptual y los tipos de interacción.

Estos materiales permiten visualizar y comprender las decisiones de diseño adoptadas durante el desarrollo de la propuesta, complementando los apartados del informe y facilitando la revisión de las evidencias del proyecto.

Los archivos se encuentran organizados en formato PNG para facilitar su consulta
